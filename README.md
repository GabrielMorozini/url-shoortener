# URL Shortener

A simple web application for shortening long URLs into shorter, more manageable links.

## About

URL Shortener is a project developed with React to create a simple and intuitive tool for shortening URLs. The project is currently under development.

## Technologies

- React
- Vite
- JavaScript
- CSS

## Getting Started

### Prerequisites

- Node.js
- npm

### Installation

Clone the repository:

```bash
git clone https://github.com/G3programmer/url-shortener.git
```

Navigate to the project directory:

```bash
cd url-shortener
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
